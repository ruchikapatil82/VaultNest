# VaultNest - Password Manager

VaultNest is a beginner-friendly password manager web application.

## Technologies

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Jinja2
- Werkzeug

## Features

- User registration
- Secure password hashing
- User login
- Session authentication
- Add password
- View password
- Edit password
- Delete password
- Search password
- Password generator
- Copy password
- SQLite database

## Installation

Create virtual environment:

python -m venv venv

Activate virtual environment:

Windows:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Run:

python app.py

Open browser:

http://127.0.0.1:5000
